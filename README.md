# 🪙 React Crypto Tracker

Um aplicativo web moderno desenvolvido em **React** para acompanhar o preço de criptomoedas em tempo real, utilizando dados públicos da [CoinGecko API](https://www.coingecko.com/).

## ✨ Recursos

- **Preços em Tempo Real:** Acompanhe cotações atualizadas das principais criptomoedas do mercado.
- **Busca Dinâmica:** Encontre rapidamente sua moeda favorita pelo nome.
- **Design Responsivo:** Interface limpa e adaptável para dispositivos móveis e desktops.

## 🛠️ Tecnologias Utilizadas

- **React.js** (com Hooks `useState` e `useEffect`)
- **Axios** para consumo da API
- **CSS** para estilização
- **CoinGecko API** como fonte de dados
